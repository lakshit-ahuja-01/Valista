# VALISTA – Smart Ownership Marketplace

VALISTA is a modern frontend marketplace platform developed using HTML, CSS, and JavaScript. The project provides an interactive product exploration experience with features such as ownership scoring, dynamic ratings, cart management, theme switching, and responsive UI design.

The platform implements frontend concepts including:

* DOM Manipulation
* Event Handling
* Functions & Arrays
* Local Storage
* Dynamic Content Rendering
* Responsive Layout Design

## Features

* User Login System
* Marketplace Navigation
* Ownership Score System
* Dynamic Star Rating
* Cart Management
* Product Feedback System
* Dark/Light Theme Toggle

## Technologies Used

* HTML
* CSS
* JavaScript
